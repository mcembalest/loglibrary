# The logarithm

The logarithm base $b$ of a number $x$ is the exponent to which $b$ must be raised to give $x$:

$$ \log_b(x) = y \iff b^y = x. $$

It is the inverse of exponentiation, defined for $x > 0$ and base $b > 0,\ b \neq 1$.

## Common bases

- Base 10 — the [common logarithm](../history/briggs.md), $\log_{10}$.
- Base $e$ — the [natural logarithm](natural-log.md), $\ln$.
- Base 2 — the binary logarithm, $\log_2$, used in [information](../interpretations/entropy.md) and [complexity](../interpretations/complexity.md).
