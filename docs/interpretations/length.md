# Length

The base-$b$ logarithm measures how many digits a number uses. A positive integer $n$ has $\lfloor \log_b n \rfloor + 1$ digits in base $b$; $\log_b n$ itself gives a continuous "length" that includes fractional digits.

For example, $\log_{10} 103 \approx 2.01$ and $\log_{10} 981 \approx 2.99$: both are three-digit numbers, but the logarithm distinguishes how fully each uses its three digits.
