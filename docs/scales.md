# Logarithmic scales

Many measurement scales are logarithmic, compressing quantities that span orders of magnitude into a linear range.

| Scale | Measures | Definition |
|---|---|---|
| Decibel | power / amplitude ratio | $10\log_{10}(P/P_0)$ |
| pH | acidity | $-\log_{10}[\mathrm{H}^+]$ |
| Richter / moment magnitude | earthquake size | $\log_{10}$ of amplitude |
| Stellar magnitude | brightness | $-2.5\log_{10}$ of flux |
| Thermodynamic entropy | number of microstates | $k_B \ln \Omega$ |

Related phenomena:

- **Benford's law** — the leading digit $d$ occurs with frequency $\log_{10}(1 + 1/d)$.
- **Weber–Fechner law** — perceived intensity scales with the logarithm of stimulus intensity.
