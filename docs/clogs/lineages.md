# Two lineages

"Continued logarithm" names two different objects.

**Gosper (1972).** A binary "recursive scientific notation," introduced to represent numbers whose continued fractions are impractical. Developed by Borwein, Calkin, Lindstrom, and Mattingly (2016), who found an elementary analogue of Khinchin's constant.

**Neunhäuserer.** For base $m \ge 3$ and digits $d_k \in \{1,\dots,m-1\}$,

$$ [(d_k)]_m = \lim_{n\to\infty} \log_m\!\big(d_1 + \log_m(d_2 + \cdots + \log_m d_n)\big), $$

a representation of every real number in $[0,1]$. Each map $T_d(x) = \log_m(d+x)$ is a contraction on $[0,1]$, so the limit exists.
