# Continued logarithms

A continued logarithm expresses a number through nested logarithms, for example

$$ \log_b\!\big(d_1 + \log_b\!\big(d_2 + \log_b(d_3 + \cdots)\big)\big). $$

The term names two distinct constructions — see [two lineages](lineages.md). The [gallery](gallery.md) plots use the nested-logarithm representation of Neunhäuserer, computed by `tools/clogs.py`.
